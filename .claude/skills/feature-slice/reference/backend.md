# Backend templates

Placeholder entity: `Widget` (package `widget`, table `widget`, URL `/api/widgets`) with fields
covering every common kind:

| Field | Kind |
| --- | --- |
| `code` | String, required, max 20, **unique case-insensitive** (normalized to lowercase) |
| `name` | String, required, max 50 |
| `kind` | enum `WidgetKind` (`SMALL`, `LARGE`), required |
| `validFrom` | LocalDate, optional |
| `active` | boolean flag, optional in request (null → false) |

Rename `Widget`/`widget`/`widgets`, drop fields you do not need, add fields following the same
shape. Keep import order, blank lines and method order as below (it is the vehicle module's).

## Migration `V<n>__widget.sql`

```sql
CREATE TABLE widget (
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    code       VARCHAR(20) NOT NULL,
    name       VARCHAR(50) NOT NULL,
    kind       VARCHAR(20) NOT NULL,
    valid_from DATE,
    active     BOOLEAN     DEFAULT FALSE NOT NULL,
    CONSTRAINT uq_widget_code UNIQUE (code)

```

Adding a column to an EXISTING table (never edit its old migration) – pattern of `V3__vehicle_fuel_type.sql`:
```sql
ALTER TABLE vehicle ADD COLUMN some_flag BOOLEAN DEFAULT FALSE NOT NULL;   -- with default: one statement
-- without a sensible default: ADD COLUMN x VARCHAR(20); UPDATE ... SET x = ...; ALTER TABLE ... ALTER COLUMN x SET NOT NULL;
```

Trimming a field that ALSO has a format validator (`@Email`, `@Pattern`, custom constraint) – validation
runs before the mapper, so trim in a compact constructor; keep lowercasing in the mapper:
```java
public record XRequest(
        @NotBlank
        @Email
        @Size(max = 100)
        String email

        // Bean Validation runs on the trimmed value; the mapper lowercases for case-insensitive uniqueness.
```

## `WidgetMapper.java`

```java
package com.example.dealership.widget;

import java.util.Locale;

public final class WidgetMapper {

    private WidgetMapper() {
    }

    public static Widget toEntity(WidgetRequest request) {
        return new Widget(
                normalizeCode(request.code()),
                request.name(),
                request.kind(),
                request.validFrom(),
                Boolean.TRUE.equals(request.active()));
    }

    public static void updateEntity(Widget widget, WidgetRequest request) {
        widget.setCode(normalizeCode(request.code()));
        widget.setName(request.name());
        widget.setKind(request.kind());
        widget.setValidFrom(request.validFrom());
        widget.setActive(Boolean.TRUE.equals(request.active()));
    }

    public static WidgetResponse toResponse(Widget widget) {
        return new WidgetResponse(
                widget.getId(),
                widget.getCode(),
                widget.getName(),
                widget.getKind(),
                widget.getValidFrom(),
                widget.isActive());
    }

    // Only for case-insensitive unique fields: the DB unique constraint then enforces it too.
    // trim() is defensive here; for format-validated fields the request's compact constructor trims first.
    static String normalizeCode(String code) {
        return code.trim().toLowerCase(Locale.ROOT);
    }
}
```

## `WidgetService.java`

```java
package com.example.dealership.widget;

import java.util.List;

import com.example.dealership.error.ConflictException;
import com.example.dealership.error.NotFoundException;

import org.springframework.data.domain.Sort;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@Transactional(readOnly = true)
public class WidgetService {

    private final WidgetRepository widgetRepository;

    public WidgetService(WidgetRepository widgetRepository) {
        this.widgetRepository = widgetRepository;
    }

    public List<WidgetResponse> findAll() {
        return widgetRepository.findAll(Sort.by("id")).stream()
                .map(WidgetMapper::toResponse)
                .toList();
    }

    public WidgetResponse findById(Long id) {
        return WidgetMapper.toResponse(getWidget(id));
    }

    @Transactional
    public WidgetResponse create(WidgetRequest request) {
        String code = WidgetMapper.normalizeCode(request.code());
        if (widgetRepository.existsByCode(code)) {
            throw codeAlreadyExists(code);
        }
        Widget widget = widgetRepository.save(WidgetMapper.toEntity(request));
        return WidgetMapper.toResponse(widget);
    }

    @Transactional
    public WidgetResponse update(Long id, WidgetRequest request) {
        Widget widget = getWidget(id);
        String code = WidgetMapper.normalizeCode(request.code());
        if (widgetRepository.existsByCodeAndIdNot(code, id)) {
            throw codeAlreadyExists(code);
        }
        WidgetMapper.updateEntity(widget, request);
        return WidgetMapper.toResponse(widgetRepository.save(widget));
    }

    @Transactional
    public void delete(Long id) {
        widgetRepository.delete(getWidget(id));
    }

    private Widget getWidget(Long id) {
        return widgetRepository.findById(id)
                .orElseThrow(() -> new NotFoundException("Widget with id " + id + " not found"));
    }

    private static ConflictException codeAlreadyExists(String code) {
        return new ConflictException("Widget with code " + code + " already exists");
    }
}
```
Without normalization use `request.code()` directly (exactly like `VehicleService` with VIN).

409 message convention: `"<Entity> with <field label in lowercase words> <stored (normalized) value> already exists"` – e.g. `"Widget with code w-001 already exists"`, `"Vehicle with VIN … already exists"`.

## `WidgetController.java`

```java
package com.example.dealership.widget;

import java.net.URI;
import java.util.List;

import jakarta.validation.Valid;

import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.servlet.support.ServletUriComponentsBuilder;

@RestController
@RequestMapping("/api/widgets")
public class WidgetController {

    private final WidgetService widgetService;

    public WidgetController(WidgetService widgetService) {
        this.widgetService = widgetService;
    }

    @GetMapping
    public List<WidgetResponse> findAll() {
        return widgetService.findAll();
    }

    @GetMapping("/{id}")
    public WidgetResponse findById(@PathVariable Long id) {
        return widgetService.findById(id);
    }

    @PostMapping
    public ResponseEntity<WidgetResponse> create(@Valid @RequestBody WidgetRequest request) {
        WidgetResponse response = widgetService.create(request);
        URI location = ServletUriComponentsBuilder.fromCurrentRequest()
                .path("/{id}")
                .buildAndExpand(response.id())
                .toUri();
        return ResponseEntity.created(location).body(response);
    }

    @PutMapping("/{id}")
    public WidgetResponse update(@PathVariable Long id, @Valid @RequestBody WidgetRequest request) {
        return widgetService.update(id, request);
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(@PathVariable Long id) {
        widgetService.delete(id);
        return ResponseEntity.noContent().build();
    }
}
```

## Custom constraint (format with checksum, cross-field rule)

Pattern of `ProductionYear` + `ProductionYearValidator`. Example `Ean13` (13 digits, weights 1,3,1,3…, check digit = (10 - sum % 10) % 10):

```java
@Documented
@Constraint(validatedBy = Ean13Validator.class)
@Target({ElementType.FIELD, ElementType.RECORD_COMPONENT})
@Retention(RetentionPolicy.RUNTIME)
public @interface Ean13 {

    String message() default "must be 13 digits with a valid check digit";

    Class<?>[] groups() default {};

    Class<? extends Payload>[] payload() default {};
}
```
```java
public class Ean13Validator implements ConstraintValidator<Ean13, String> {

    @Override
    public boolean isValid(String value, ConstraintValidatorContext context) {
        if (value == null) {
            return true;   // null is @NotNull's job (or the field is optional)
        }
        // … pure check, no Spring beans
    }
}
```
Cross-field rules (e.g. `endDate >= startDate`): class-level constraint on the record
(`@Target(ElementType.TYPE)`), reported with `field: null`, or – if the field name must be in
`errors[]` – build it with `context.buildConstraintViolationWithTemplate(...).addPropertyNode("endDate")`.
Rules that need "today" or other rows go to the service with an injected `java.time.Clock`.

## Nested variant: `/api/parents/{parentId}/children`

Use when the entity belongs to a parent (e.g. inspections of a vehicle). Differences only:

- Migration: `parent_id BIGINT NOT NULL`, `CONSTRAINT fk_<table>_<parent> FOREIGN KEY (parent_id) REFERENCES <parent>(id) ON DELETE CASCADE`, plus `CREATE INDEX ix_<table>_<parent> ON <table>(parent_id);`.
- Entity: plain `@Column(name = "parent_id", nullable = false) private Long parentId;` (no `@ManyToOne` – keeps the entity simple, `open-in-view=false` makes lazy relations fragile). Constructor takes `parentId` first. No setter for `parentId`.
- Request: no `parentId` (it comes from the path). Response: `id`, `parentId`, then fields.
- Repository:
  ```java
  List<Child> findByParentId(Long parentId, Sort sort);
  Optional<Child> findByIdAndParentId(Long id, Long parentId);
  ```
- Service: inject the parent repository too; every method takes `parentId` first and starts with
  `requireParent(parentId)` → `NotFoundException("Parent with id N not found")` (same message as the parent module).
  Child lookup `findByIdAndParentId` → `NotFoundException("Child with id N not found")` – a child of another parent is a 404.
  `findAll(parentId)` → `findByParentId(parentId, Sort.by("id"))`.
- Mapper: `toEntity(Long parentId, ChildRequest request)`.
- Controller: `@RequestMapping("/api/parents/{parentId}/children")`, every handler has `@PathVariable Long parentId`; `Location` still via `fromCurrentRequest().path("/{id}")`.
- Generate only the operations the user asked for (a contract may have no PUT/DELETE). Extra endpoints are a bug, not a bonus.
- Parent check: `parentRepository.existsById(parentId)` when the parent entity itself is not needed, `findById` when its fields are (e.g. a date used in a rule). The child service may depend on the parent feature's repository – that is the only allowed cross-package dependency.
- Seed: reference parents by a unique key subselect (`(SELECT id FROM vehicle WHERE vin = '…')`), never hard-coded ids.
- Location header still uses `fromCurrentRequest().path("/{id}")` even when there is no GET-by-id (consistent with the vehicle module); mention it in the report.

## Partial operations (contract lists only some endpoints)

Generate **only** what is used: no `updateEntity` without PUT, no `findByIdAndParentId` without an
endpoint addressing a single child, no `exists…` without a uniqueness rule. Dead code fails review.

## Server-managed fields (status, timestamps, computed flags)

- Not in the request record (unknown JSON properties are ignored by Jackson – add a controller test that a
  posted value is ignored).
- Initial value set in `Mapper.toEntity` (e.g. `Status.PENDING`), with a one-line comment why.
- In the entity constructor and response; TS request type omits it; shown in list/detail, never in the form.
- Changing it later is a business operation (own endpoint, e.g. `PUT …/{id}/status`), not part of the generic update.
